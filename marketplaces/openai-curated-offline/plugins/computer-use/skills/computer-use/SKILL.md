# Computer Use: computer-use

Control local Mac apps through Computer Use for tasks that require reading or operating app UI. Prefer purpose-built connectors, APIs, or CLIs when available.

If this workflow requires an account-backed connector, use the installed app/connector for Computer Use. If authorization is missing, ask the user to connect Computer Use before taking account actions.
