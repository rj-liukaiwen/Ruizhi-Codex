# SharePoint: sharepoint-word-docs

Edit SharePoint-hosted Word `.docx` files while preserving document structure and styling. Use when the user wants to update a real Word document in SharePoint rather than summarize it as plain text.

If this workflow requires an account-backed connector, use the installed app/connector for SharePoint. If authorization is missing, ask the user to connect SharePoint before taking account actions.
