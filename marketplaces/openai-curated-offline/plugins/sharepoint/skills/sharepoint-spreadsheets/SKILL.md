# SharePoint: sharepoint-spreadsheets

Edit SharePoint-hosted spreadsheet files while preserving workbook structure, formulas, and formatting. Use when the user wants to update a real spreadsheet in SharePoint rather than summarize extracted sheet text.

If this workflow requires an account-backed connector, use the installed app/connector for SharePoint. If authorization is missing, ask the user to connect SharePoint before taking account actions.
