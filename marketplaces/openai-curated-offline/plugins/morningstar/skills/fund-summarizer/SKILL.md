# Morningstar: fund-summarizer

Use when summarizing a fund or ETF with Morningstar ratings, returns, risk, holdings, fees, and caveats.

If this workflow requires an account-backed connector, use the installed app/connector for Morningstar. If authorization is missing, ask the user to connect Morningstar before taking account actions.
