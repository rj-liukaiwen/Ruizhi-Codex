# Teams: teams-planner-task-management

Review and manage Microsoft Planner tasks from Teams workflows. Use when the user wants to inspect plans or buckets, create tasks from follow-ups, update task fields, or safely delete a Planner task.

If this workflow requires an account-backed connector, use the installed app/connector for Teams. If authorization is missing, ask the user to connect Teams before taking account actions.
