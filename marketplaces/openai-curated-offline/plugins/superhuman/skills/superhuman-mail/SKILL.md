# Superhuman Mail: superhuman-mail

Use Superhuman Mail MCP for email and calendar workflows such as searching inboxes, reading threads, drafting or sending mail, managing labels, checking read statuses, finding availability, and creating or updating events.

If this workflow requires an account-backed connector, use the installed app/connector for Superhuman Mail. If authorization is missing, ask the user to connect Superhuman Mail before taking account actions.
