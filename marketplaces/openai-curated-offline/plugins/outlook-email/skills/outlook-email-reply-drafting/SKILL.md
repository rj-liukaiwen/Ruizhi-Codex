# Outlook Email: outlook-email-reply-drafting

Draft Outlook email replies safely from connected mailbox context. Use when the user wants to reply to a thread, decide whether to reply-all, prepare a draft before sending, or turn the latest Outlook message into a polished response.

If this workflow requires an account-backed connector, use the installed app/connector for Outlook Email. If authorization is missing, ask the user to connect Outlook Email before taking account actions.
