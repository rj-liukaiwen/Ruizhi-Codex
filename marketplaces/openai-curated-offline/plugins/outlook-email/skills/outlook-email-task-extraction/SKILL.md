# Outlook Email: outlook-email-task-extraction

Extract action items, deadlines, commitments, and owners from Outlook email threads and mailbox searches. Use when the user wants a task list from one thread, several related messages, or a mailbox slice, including who owes what and when.

If this workflow requires an account-backed connector, use the installed app/connector for Outlook Email. If authorization is missing, ask the user to connect Outlook Email before taking account actions.
