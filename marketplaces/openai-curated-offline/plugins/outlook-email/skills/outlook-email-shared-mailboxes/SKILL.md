# Outlook Email: outlook-email-shared-mailboxes

Work with delegated or shared Outlook Email mailboxes. Use when the user explicitly wants to read another mailbox, send from or on behalf of a shared mailbox, mark shared mail read or unread, move shared mail, or browse folders in a shared mailbox.

If this workflow requires an account-backed connector, use the installed app/connector for Outlook Email. If authorization is missing, ask the user to connect Outlook Email before taking account actions.
