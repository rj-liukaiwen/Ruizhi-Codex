# Outlook Calendar: outlook-calendar-shared-calendars

Safely write to delegated or shared Outlook calendars. Use when the user explicitly wants to create, update, respond to, cancel, delete, or add a small attachment to an event on a shared or delegated Outlook Calendar.

If this workflow requires an account-backed connector, use the installed app/connector for Outlook Calendar. If authorization is missing, ask the user to connect Outlook Calendar before taking account actions.
