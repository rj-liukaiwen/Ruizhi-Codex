# Outlook Calendar: outlook-calendar-daily-brief

Build polished one-day Outlook Calendar briefs. Use when the user asks for today, tomorrow, or a specific date summary with an agenda, conflict flags, free windows, remaining-meeting readouts, or a calendar brief, and Outlook Calendar is available.

If this workflow requires an account-backed connector, use the installed app/connector for Outlook Calendar. If authorization is missing, ask the user to connect Outlook Calendar before taking account actions.
