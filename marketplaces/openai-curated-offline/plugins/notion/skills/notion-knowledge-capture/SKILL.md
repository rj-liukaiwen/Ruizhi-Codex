# Notion: notion-knowledge-capture

Capture conversations and decisions into structured Notion pages; use when turning chats/notes into wiki entries, how-tos, decisions, or FAQs with proper linking.

If this workflow requires an account-backed connector, use the installed app/connector for Notion. If authorization is missing, ask the user to connect Notion before taking account actions.
