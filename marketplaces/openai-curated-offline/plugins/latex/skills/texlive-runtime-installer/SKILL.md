# LaTeX: texlive-runtime-installer

Detect existing TeX Live or MacTeX first, then optionally install a Codex-managed full TeX Live runtime only when no existing TeX Live installation is detected.

If this workflow requires an account-backed connector, use the installed app/connector for LaTeX. If authorization is missing, ask the user to connect LaTeX before taking account actions.
