# LaTeX: latex-compile

Compile a TeX project from Codex, trying bundled Tectonic for simple projects and falling back to detected TeX Live or MacTeX when needed.

If this workflow requires an account-backed connector, use the installed app/connector for LaTeX. If authorization is missing, ask the user to connect LaTeX before taking account actions.
