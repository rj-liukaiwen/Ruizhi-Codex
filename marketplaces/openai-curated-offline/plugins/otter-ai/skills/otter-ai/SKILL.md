# Otter.ai: otter-ai

The Otter.ai MCP server connects Codex to your meeting intelligence, enabling search and retrieval of transcripts, summaries, action items, and meeting metadata directly within your workflow.

If this workflow requires an account-backed connector, use the installed app/connector for Otter.ai. If authorization is missing, ask the user to connect Otter.ai before taking account actions.
