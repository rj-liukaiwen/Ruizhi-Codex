# Life Sciences NGS Analysis: ngs-fastq-qc

Validate FASTQ inputs, run local FastQC/MultiQC QC, interpret QC signals, and optionally execute fastp or Cutadapt trimming branches without overwriting raw reads.

If this workflow requires an account-backed connector, use the installed app/connector for Life Sciences NGS Analysis. If authorization is missing, ask the user to connect Life Sciences NGS Analysis before taking account actions.
