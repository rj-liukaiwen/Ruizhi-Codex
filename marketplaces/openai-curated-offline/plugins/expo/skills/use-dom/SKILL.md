# Expo: use-dom

Use Expo DOM components to run web code in a webview on native and as-is on web. Migrate web code to native incrementally.

If this workflow requires an account-backed connector, use the installed app/connector for Expo. If authorization is missing, ask the user to connect Expo before taking account actions.
